# Social media for scheduled posts

Pictures and videos for Muse Labs' scheduled posts (Buffer needs public links to post them). They're posted publicly anyway. One folder per batch; the site itself never uses this branch, and nothing here deploys.

- `week-1125/`: the week of Nov 25 to Dec 2, 2026 (Social Hub batch week-1125). The three videos carry Jason's own tracks from Muse Jukebox (Callout, Bell Drop, Exhale). The `four-apps-light-*` slides (Nov 25) replace `four-apps-*` for the Friday carousel, so it looks different from the first post. `penguin-callout-sfx.mp4` (Nov 25) is the penguin clip with the app's own penguin sounds (the + button's boing, the pick-up eep, the throw's whee and the landings) mixed over Callout.
